# Classroom Santhali Evaluation Dataset

This directory will hold human-reviewed Santhali sentences categorized for foundational literacy and numeracy.

## Categories
- `foundational_literacy.jsonl` (letters, phonics, reading)
- `numeracy.jsonl` (numbers, counting, shapes)
- `classroom.jsonl` (instructions, activities)
- `local_context.jsonl` (village, forest, agriculture)
