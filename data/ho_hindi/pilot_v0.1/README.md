# MatriVaani Ho-Hindi Pilot Dataset v0.1

This directory is the staging area for the Ho-Hindi parallel pilot dataset.
Currently, the dataset is EMPTY because the project lacks verified bilingual human annotators to safely generate Ho-Hindi pairs. Machine translation is strictly prohibited for bootstrapping this low-resource Austroasiatic language.

## Required Next Steps
1. Procure Ho ASR transcripts (Devanagari).
2. Hire/assign human translators to translate them into Hindi.
3. Validate translations according to the MatriVaani Phase 6E quality standards.
4. Populate train.jsonl, validation.jsonl, test.jsonl.
