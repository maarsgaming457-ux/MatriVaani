# CAPABILITY MATRIX

## LANGUAGES
- **Hindi**
- **Santali**
- **Ho**

## TRANSLATION
- **Hindi -> Santali**: Supported
- **Santali -> Hindi**: Supported (when current backend path / WSL server is available)
- **Ho -> Hindi**: Not available
- **Ho -> Santali**: Not available
- **Hindi -> Ho**: Not available
- **Santali -> Ho**: Not available

## ASR (Automatic Speech Recognition)
- **Hindi**: Supported (via existing path)
- **Santali**: Supported (where configured)
- **Ho**: Supported (local Ho ASR)

## TTS (Text-to-Speech)
- **Hindi**: Supported (where configured via Sarvam)
- **Santali**: Supported (where configured)
- **Ho**: Not available
