# DEMO SCRIPT

## 1. Hindi -> Santali Educational Translation
- Open App
- Select Hindi as source, Santali as target
- Press Mic: "नमस्ते बच्चों, आज हम गिनती सीखेंगे।"
- Observe: ASR captures Hindi correctly.
- Observe: Translation outputs correct Santali text.
- Observe: Audio plays the Santali speech.

## 2. Ho ASR Verification
- Select Ho as source
- Press Mic: "आबू एन हो को नेनता काबु बेटा इचि कोआ"
- Observe: Correct Ho Devanagari text.
- Observe: Translation blocked with "Ho translation is not yet available in the current prototype."
