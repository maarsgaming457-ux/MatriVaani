# FINAL DEMO README

Welcome to the MatriVaani final submission. This prototype focuses on vernacular primary education.

## Quick Start
1. Start Backend: python app/api/main.py
2. Start IndicTrans2 (WSL): wsl bash -c "python indictrans2_server.py"
3. Install Flutter APK on Android device: FINAL_SUBMISSION_V2/android/build/app/outputs/flutter-apk/app-release.apk

# DEMO GUIDE

## Prerequisites
- Android Phone
- Windows Laptop with WSL
- Wi-Fi network

## Paths
1. **Hindi to Santali Classroom**: Speak Hindi, get translated to Santali text/audio.
2. **Ho Speech Collection**: Speak Ho, verify ASR text generation. Translation intentionally blocked.
3. **Offline Sync**: Disable Wi-Fi, add offline flashcards, enable Wi-Fi, verify sync.
